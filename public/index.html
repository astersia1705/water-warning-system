ตารางเปรียบเทียบข้อมูลสกัดจากโซเชียลมีเดีย (Database 2) เทียบกับสถานีตรวจวัดของหน่วยงานภาครัฐ เพื่อยืนยันความน่าเชื่อถือของระบบ:

หน่วยงานอ้างอิง พื้นที่ตรวจวัด ค่ามาตรฐาน/ข้อมูลทางการ ข้อมูลที่พบจากโพสต์โซเชียล สถานะการยืนยัน
กรมควบคุมมลพิษ (คพ.) อ.แม่สาย จ.เชียงราย (แม่น้ำกก-แม่น้ำสาย) / จ.ปราจีนบุรี พบค่าสารหนูเกินเกณฑ์ 28 เท่า, สารตะกั่วเกินมาตรฐาน 5 เท่า จากเหมืองแร่ข้ามแดน พบรายงานน้ำแม่น้ำสายสีขุ่นเข้มผิดปกติ มีสารพิษปนเปื้อนในข้าวและพืชผลการเกษตร ✓ สอดคล้องตรงกัน 100%
GISTDA (ภาพถ่ายดาวเทียม) ลุ่มน้ำปราจีนบุรี - บางปะกง (อ.บ้านสร้าง, อ.บางคล้า, อ.บางน้ำเปรี้ยว) ดาวเทียมพบพื้นที่น้ำท่วมขังสะสมในพื้นที่ลุ่มต่ำเกษตรกรรมกว่า 100,000 ไร่ ชาวบ้านรายงานน้ำท่วมขังนานกว่า 20–30 วัน น้ำไม่ลด และเกิดน้ำเน่าขังในสวน ✓ สอดคล้องตรงกัน 100%
กรมชลประทาน (RID) ประตูระบายน้ำคลองท่าลาด / แม่น้ำบางปะกง เร่งเปิดบานประตูระบายน้ำเพิ่ม 50 ซม. เพื่อระบายมวลน้ำค้างทุ่งลงสู่แม่น้ำสายหลัก โพสต์รายงานชาวบ้าน ต.ศาลาแดง เรียกร้องให้เปิดประตูระบายน้ำเพื่อลดน้ำท่วมขัง ✓ ยืนยันเหตุการณ์จริง
กรมอุตุนิยมวิทยา (TMD) ภาคตะวันออก และภาคเหนือ (น่าน, เชียงราย) ประกาศเตือนฝนตกหนักถึงหนักมากสะสมในช่วงเดือน ก.ย. - ต.ค. รายงานน้ำป่าไหลหลากเข้าท่วมพื้นที่ อ.กบินทร์บุรี และ อ.ปัว จ.น่าน ✓ สอดคล้องตามฤดูกาล
